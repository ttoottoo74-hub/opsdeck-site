개인정보처리방침

시행일: 2026년 9월 16일 · 최종 개정: 2026년 10월 7일 (담뿍 원격 콘솔·게시판, 크롬 확장 전송처 명확화)

담뿍(이하 "회사")은 콘텐츠 운영 자동화 콘솔 OpsDeck(이하 "서비스")을 제공합니다. 이 방침은 서비스가 어떤 정보를 다루고, 그 정보가 어디에 저장되며, 연결된 소셜 미디어 계정에 무엇을 하는지 설명합니다.

핵심 요약

  • 설치형 OpsDeck는 이용자의 컴퓨터에서 실행됩니다. 설정과 콘텐츠는 그 컴퓨터에만 저장됩니다.
  • 회사가 이용자에게 전용 주소(예: rv-이름.dambuk.co.kr)를 발급해 운영하는 원격 콘솔을 쓰는 경우에는, 그 이용자의 설정·콘텐츠와 로그인 이메일이 회사가 운영하는 서버에 저장됩니다(아래 1-2절). 회사는 이 정보를 서비스 제공과 오류 해결에만 쓰며, 판매하거나 광고에 쓰지 않습니다.
  • 연결된 SNS 계정에는 이용자가 승인한 콘텐츠를 게시하는 용도로만 접근합니다.
  • 연결 해제는 각 플랫폼 설정에서 언제든 가능하며, 즉시 효력이 생깁니다.
  • OpsDeck는 YouTube API 서비스를 사용합니다. YouTube 기능을 사용하면 Google 개인정보처리방침이 함께 적용됩니다.

1. 처리하는 정보

1-1. 설치형(이용자 컴퓨터에서 실행)

설치형 서비스는 아래 정보를 이용자의 기기에 저장합니다. 회사 서버로 전송되지 않습니다.

구분내용저장 위치
연동 자격증명이용자가 직접 입력한 API 키, 액세스 토큰이용자 기기의 설정 파일
채널 설정채널 주제, 발행 일정, 문체 규칙 등 이용자가 정한 값이용자 기기의 로컬 데이터베이스
생성 콘텐츠원고, 이미지, 영상, 음성 파일이용자 기기의 파일 폴더
실행 기록작업 단계, 승인 이력, 오류 로그, 비용 집계이용자 기기의 로컬 데이터베이스

서비스는 이용자의 이름, 연락처, 주소, 결제 정보, 위치 정보, 연락처 목록, 기기 식별자를 수집하지 않습니다. 이용 행태를 추적하는 분석 도구나 광고 식별자를 사용하지 않습니다.

1-2. 담뿍 원격 콘솔(회사가 발급한 전용 주소)

회사가 이용자에게 전용 주소를 발급해 운영하는 원격 콘솔을 쓰는 경우, 아래 정보는 회사가 운영하는 서버(대한민국 소재)에 저장됩니다.

구분내용목적
로그인 정보로그인에 쓴 이메일 주소(접속 인증 서비스가 확인한 값)본인 확인, 전용 주소 접근 허용
이용자가 입력한 정보기본정보 설문 답(닉네임, 블로그 주소, 이용자가 적은 관심사 등), 캠페인 정보, 메모, 올린 사진·영상원고·클립 작성
생성 콘텐츠·실행 기록원고, 이미지, 영상, 작업 단계, 승인 이력, 오류 기록, AI 비용 집계서비스 제공, 오류 해결
게시판오류 신고·개선 요청·사용 후기 글과 댓글, 첨부한 화면 캡처, 별명, 글에 자동으로 붙는 정보(채널 이름, 보던 화면 주소, 브라우저 종류, 프로그램 버전)문의 응대, 서비스 개선
이용 기록마지막으로 콘솔을 쓴 시각쓰지 않을 때 이용자 전용 콘솔을 잠시 끄기

게시판 글은 이용자가 "같은 팩 사용자 모두" 또는 "나와 운영자만" 중에서 공개 범위를 고르며, 다른 이용자에게 이메일은 보이지 않습니다. 화면 캡처에 개인정보가 담기지 않도록 주의해 주세요. 회사는 위 정보를 서비스 제공·오류 해결·문의 응대에만 쓰고, 판매하거나 광고·신용 판단에 쓰지 않으며, 법령에 따른 경우 외에는 제3자에게 제공하지 않습니다.

2. 연결된 소셜 미디어 계정

이용자가 자신의 계정을 연결하면, 서비스는 해당 플랫폼이 발급한 토큰을 이용자 기기에 저장하고 아래 범위에서만 사용합니다.

Instagram

  • instagram_business_basic — 연결된 계정이 맞는지 확인하기 위해 계정 식별자와 사용자 이름을 조회합니다.
  • instagram_business_content_publish — 이용자가 승인한 이미지·영상을 해당 계정에 게시합니다.

TikTok

  • user.info.basic — 연결된 계정이 맞는지 확인하기 위해 기본 프로필 정보를 조회합니다.
  • video.upload — 이용자가 승인한 영상을 이용자 계정의 초안함으로 전송합니다. 게시 여부는 이용자가 TikTok 앱에서 직접 결정합니다.
  • video.publish — (해당 권한이 승인된 경우) 이용자가 승인한 영상을 이용자 계정에 게시합니다.

YouTube (YouTube API 서비스)

OpsDeck는 YouTube API 서비스를 사용해 이용자 본인의 YouTube 채널에 영상을 올립니다. YouTube 기능을 사용하면 Google 개인정보처리방침이 함께 적용됩니다.

  • youtube.upload — 이용자가 승인한 숏폼 영상과 그 제목·설명을 이용자 채널에 업로드합니다.
  • youtube.readonly — 연결된 채널이 맞는지 확인하기 위해 채널 이름, 핸들, 채널 ID, 영상 수를 조회합니다. 조회한 값은 연결 확인 화면에 표시만 하고 저장하지 않습니다.

서비스가 저장하는 YouTube 관련 정보는 Google이 발급한 갱신 토큰(refresh token) 하나뿐이며, 이용자 기기의 설정 파일에만 저장됩니다. 업로드에 필요한 액세스 토큰은 메모리에만 두고 파일로 남기지 않습니다. 서비스는 이용자 채널의 기존 영상, 댓글, 구독자, 시청 기록, 분석 데이터를 조회하거나 저장하지 않습니다.

공통

서비스는 연결된 계정에서 다음을 하지 않습니다: 기존 게시물이나 댓글·메시지를 수집·저장·분석하는 행위, 팔로워 목록이나 인사이트를 추출하는 행위, 이용자 콘텐츠를 제3자에게 제공하거나 판매하는 행위, 다른 이용자의 계정에 접근하는 행위, 자동 팔로우·좋아요 등 참여 조작 행위.

크롬 확장 (담뿍 – 블로그·클립 글 채우기)

  • 무엇을 읽나요: 이용자가 직접 연 체험단 캠페인 페이지(제목·주소·본문 글·링크), 그리고 네이버 블로그 글쓰기·클립 업로드 화면의 채움 상태를 읽습니다.
  • 어디로 보내나요: 이용자가 연결한 담뿍 콘솔로만 보냅니다. 이용자 컴퓨터의 설치형 콘솔이거나, 회사가 이용자에게 발급한 전용 주소(원격 콘솔, 1-2절)입니다. 그 밖의 제3자에게 보내지 않습니다.
  • 저장하지 않는 것: 네이버·체험단 사이트의 아이디, 비밀번호, 쿠키와 이용자의 열람 기록은 읽거나 저장하지 않습니다.
  • 브라우저에 저장하는 것: 담뿍 주소, 채널 이름, 연결 토큰, 대기 글 제목 목록(확장을 지우면 함께 지워집니다).
  • 발행·등록 버튼은 확장이 누르지 않으며, 이용자가 직접 누릅니다. 판매·광고·신용 판단 목적으로 쓰지 않습니다.
  • 확장이 다루는 데이터는 위에 적은 기능(글 채우기, 캠페인 담기)에만 쓰며, Chrome 웹스토어 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 외부 서비스로의 전송

콘텐츠를 만들고 발행하려면 아래 서비스로 데이터가 전송됩니다. 전송은 이용자가 해당 기능을 사용할 때만 일어나며, 각 서비스의 개인정보처리방침이 함께 적용됩니다.

4. 보관과 파기

설치형: 모든 데이터는 이용자의 기기에 보관되며, 보관 기간은 이용자가 정합니다. 연결을 해제하면 콘솔은 해당 플랫폼의 토큰을 설정 파일에서 삭제하며, 이용자는 콘솔의 환경변수 화면에서 토큰을 직접 지울 수도 있습니다. 콘솔에서 항목을 삭제하거나 데이터 폴더를 지우면 즉시 파기됩니다. 프로그램을 삭제하면 해당 데이터도 함께 제거됩니다.

원격 콘솔: 이용자가 이용을 끝내거나 삭제를 요청하면 전용 주소를 닫고, 그 이용자의 데이터는 실수로 지운 경우에 대비해 30일간 보관한 뒤 파기합니다. 장애 대비 백업 사본은 최대 7일 보관 후 자동으로 지워집니다. 게시판 글은 이용자가 지우면 다른 이용자에게 보이지 않게 되며, 완전 삭제를 원하시면 아래 문의처로 요청해 주세요(30일 이내 처리).

5. 연결 해제와 권한 철회

이용자는 언제든 연결을 끊을 수 있습니다.

  • 콘솔에서: 환경변수 설정에서 해당 토큰을 지우고 저장합니다.
  • Instagram: 설정 → 앱 및 웹사이트에서 OpsDeck 연결을 삭제합니다.
  • TikTok: 설정 → 보안 및 로그인 → 앱 관리에서 OpsDeck 권한을 해제합니다.
  • YouTube: Google 보안 설정의 서드파티 액세스 페이지에서 OpsDeck의 액세스 권한을 삭제합니다.

권한을 해제하면 서비스는 해당 계정에 더 이상 접근할 수 없습니다. 플랫폼에서 받은 데이터의 삭제를 요청하시려면 아래 문의처로 연락해 주시기 바라며, 요청 접수 후 30일 이내에 처리합니다.

6. 아동의 개인정보

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다. 각 소셜 미디어 플랫폼이 정한 최소 연령 요건이 함께 적용됩니다.

7. 안전조치

자격증명은 이용자 기기의 설정 파일에 저장되며, 콘솔 화면에서는 가려진 상태로 표시됩니다. 외부 서비스와의 통신은 모두 HTTPS로 이루어집니다. 다만 기기 자체의 보안(운영체제 계정 보호, 디스크 암호화 등)은 이용자의 관리 범위에 있습니다.

8. 방침의 변경

이 방침이 바뀌면 이 페이지에 개정일과 함께 게시합니다. 중요한 변경은 시행 7일 전에 안내합니다.

Privacy Policy (English Summary)

Effective 16 September 2026; last updated 7 October 2026. OpsDeck is a desktop application operated by Dambbuk (담뿍), Republic of Korea.

Where data lives

OpsDeck runs on the user's own computer. Credentials, channel settings, generated content and run history are stored locally on that computer only. We do not operate a server that receives, stores or analyses user content or account data. We collect no names, contact details, payment data, location data or device identifiers, and use no analytics or advertising SDKs.

Hosted console. When we issue a user a dedicated address we operate (for example rv-name.dambuk.co.kr), that user's settings, inputs (survey answers, campaign details, notes, uploaded photos and videos), generated content, run history, community-board posts with attached screenshots, the time the console was last used, and the sign-in email address verified by our access provider are stored on a server we operate in the Republic of Korea. We use this data only to provide the service, fix errors and answer enquiries; we do not sell it, use it for advertising or credit decisions, or share it with third parties except as required by law. Other users never see a poster's email address.

Connected social accounts

When a user connects their own account, the platform-issued token is stored on the user's device and used only within these scopes:

  • Instagram — instagram_business_basic to confirm which account is connected; instagram_business_content_publish to publish media the user has approved.
  • TikTok — user.info.basic to confirm which account is connected; video.upload to send an approved video to the user's own drafts, where the user decides whether to post it; video.publish, where granted, to publish a video the user approved.
  • YouTube — OpsDeck uses YouTube API Services. youtube.upload to upload a short video the user approved, with its title and description, to the user's own channel; youtube.readonly to show the connected channel's title, handle, channel ID and video count so the user can confirm the right channel is connected. These values are displayed only and not stored. The only YouTube-related data stored is the Google-issued refresh token, kept in a settings file on the user's own device; access tokens are held in memory only. OpsDeck does not read or store existing videos, comments, subscribers, watch history or analytics. By using YouTube features, users are also subject to the Google Privacy Policy.

OpsDeck publishes only to the connecting user's own account. It does not read, store or analyse existing posts, comments or messages; does not extract follower lists or insights; does not sell or share user content with third parties; does not access any other person's account; and performs no engagement automation such as auto-following or auto-liking.

Chrome extension

The browser extension reads only the review-campaign page the user opens (title, address, body text and links) and the fill state of the Naver Blog editor and Naver Clip upload screens. It sends this data only to the Dambbuk console the user connects — either the user's own installed console or the hosted console address we issued to that user — and to no other third party. It does not read or store site IDs, passwords, cookies or browsing history. It keeps the console address, channel name, a connection token and a list of pending post titles in browser storage, which is removed when the extension is uninstalled. The extension never clicks publish or register buttons; the user does. Data is not sold or used for advertising or credit decisions. The extension's use of data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Third-party processing

To produce and publish content, data is sent to the services the user has enabled: LLM providers (Anthropic, OpenAI) for drafting, ElevenLabs for speech synthesis, Pixabay for stock search, a messenger (e.g. Telegram) for the approval step, and the publishing platforms themselves. Each provider's own privacy policy applies. For the hosted console, Cloudflare handles sign-in and encrypted delivery, and new community-board post titles are sent to the operator's messenger. For the installed application we retain nothing from these exchanges.

Retention, deletion and revocation

The user controls retention entirely; deleting an item in the console, deleting the data folder, or uninstalling the application destroys the data immediately. Access can be revoked at any time by clearing the token in the console, from Instagram (Settings → Apps and Websites), from TikTok (Settings → Security and login → Manage app permissions), or for YouTube from the Google security settings page. To request deletion of data obtained from a platform, contact us at the address below; we respond within 30 days. For the hosted console, when a user stops using it or asks for deletion we close the address, keep the data for 30 days in case of mistakes and then destroy it; disaster-recovery backups are kept for at most 7 days. Community-board posts can be hidden by their author, and fully deleted on request within 30 days.

Children

The service is not directed to children under 14, and we do not knowingly collect their personal information. Each platform's own minimum-age requirements also apply.
